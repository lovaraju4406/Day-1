# 🌐 Modern Responsive Landing Page

## 🧭 Overview
This project is a **modern, responsive landing page** built using **HTML5** and **CSS3**.  
It features a clean, professional design with a **fixed glass-style header**, an **animated hero section**, and **responsive layouts** using Flexbox and Grid.  
The page is fully mobile-friendly and visually appealing across all devices.

---

## 🎯 Objective
To design and build a **responsive landing page** that adapts to various screen sizes while maintaining a modern look and smooth user experience.

---

## 🛠️ Tools & Technologies Used
- **HTML5** – structure of the webpage  
- **CSS3** – styling, animations, and responsiveness  
- **Flexbox & CSS Grid** – for clean layout and alignment  
- **Media Queries** – to ensure mobile responsiveness  
- **VS Code** – development environment  
- **Live Server** – real-time browser preview

## ⚙️ How It Works

### 🧱 Header
- Includes **brand logo** and **navigation bar** with links.  
- Uses **Flexbox** for horizontal layout.  
- Contains a **menu toggle (☰)** for small screens.  
- On mobile, navigation becomes a vertical dropdown using **media queries**.

### 🎬 Hero Section
- Displays a **background image** with a **gradient overlay**.  
- Includes a **headline**, **paragraph**, and a **call-to-action button**.  
- The hero text uses **fade-in animation** on load.  
- Button has a **gradient hover effect** for interactivity.

### 💡 Features Section
- Contains **three responsive cards** arranged using **CSS Grid**.  
- Each card showcases a key feature with emoji icons, titles, and text.  
- Adds **hover lift and shadow animation** for a modern look.

### 🧾 Footer
- Contains **copyright**
  and **social media icons** with hover effects.  
- Maintains consistent theme colors.
